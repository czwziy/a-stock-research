# A股主板股票一键分析脚本

基于 a-stock-data SKILL.md V3.2.2 指南开发的股票分析工具。

## 功能特性

- **支持范围**：沪深主板股票（600/601/603/605/000/001/002/003）
- **13个分析模块**：
  1. 实时行情（腾讯财经）
  2. 基本面信息（东财）
  3. 板块归属（东财）
  4. 财务快照（mootdx）
  5. 机构一致预期（同花顺）
  6. 近期研报（东财）
  7. 当日资金流向（东财）
  8. 近120日资金流向（东财）
  9. 融资融券（东财）
  10. 股东户数变化（东财）
  11. 分红送转历史（东财）
  12. 限售解禁预警（东财）
  13. 近期新闻（东财）

## 安装依赖

```bash
pip install mootdx requests pandas stockstats lxml
```

## 使用方法

### 命令行使用

```bash
# 使用股票代码
python stock_analyzer.py 001218

# 使用股票名称（自动搜索代码）
python stock_analyzer.py 丽臣实业
```

### Python 代码调用

```python
from stock_analyzer import analyze_stock

# 分析股票
analyze_stock("001218")
```

## 注意事项

1. **网络要求**：部分接口（mootdx、东财 push2）需要国内网络环境
2. **数据源优先级**：优先使用不封IP的数据源（mootdx/腾讯），东财接口已内置限流防封
3. **代理问题**：如遇代理连接错误，请检查网络环境或设置正确的代理配置
4. **数据延迟**：部分数据（如资金流向）仅在交易时间更新

## 数据源说明

- **腾讯财经**：实时行情、PE/PB/市值等（不封IP）
- **东财**：基本面、板块归属、研报、资金流向、融资融券、股东户数、分红、解禁、新闻（已内置限流）
- **mootdx**：财务快照、K线数据（TCP协议，需国内网络）
- **同花顺**：机构一致预期EPS
